# Contributing

1. Create a short-lived feature branch from `main`.
2. Keep content updates truthful, minimal and bilingual; never publish secrets or details from private projects.
3. Run `npm run verify` with Node.js 22+.
4. Open a Pull Request and wait for CI before merging to `main`.
5. Changes merged into `main` trigger the GitHub Pages deployment workflow.

Keep the site dependency-light and accessible. Prefer semantic HTML and platform APIs over introducing new dependencies.
