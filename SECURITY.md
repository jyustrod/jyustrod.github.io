# Security policy

This is a static site with no server code, user data processing, forms, analytics or credentials.

- Never commit secrets, tokens, credentials or content from private repositories.
- Avoid adding third-party scripts or trackers without a privacy and security review.
- Report sensitive security findings privately to the repository owner rather than opening a public issue.
- Keep GitHub Actions up to date through Dependabot and review changes before merging.

The contact email on the public site is intentionally public for professional contact.
